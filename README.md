# Caio Silveira — Soluções Digitais

Site profissional pessoal de Caio Silveira, criado para apresentar soluções digitais para negócios de forma clara e direta.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- GSAP

## Desenvolvimento

Use `npm install` e `npm run dev`.

## Build

Use `npm run build`.
